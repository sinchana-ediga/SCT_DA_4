# SCT_DA_4 - Marketing Campaign Analysis

## Task 4: Marketing Campaign Analysis

### Objective
Analyze marketing campaign data to evaluate channel performance and identify channels that should receive more budget based on ROI.

### Tools Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Plotly

### Work Performed
- Cleaned and prepared the marketing campaign dataset.
- Performed Exploratory Data Analysis (EDA).
- Analyzed ROI across different marketing channels.
- Compared conversion rates and acquisition costs.
- Analyzed engagement scores.
- Created visualizations to understand channel performance.
- Created a marketing funnel visualization.
- Developed business insights and budget recommendations.

### Key Insights
- Email achieved the highest average ROI.
- Google Ads achieved the highest conversion rate.
- Website had the lowest average acquisition cost.
- Instagram had the highest engagement score but the lowest ROI.

### Budget Recommendation
More budget should be allocated to Email and Google Ads because of their strong performance. Website campaigns should be maintained due to their cost efficiency, while Instagram and other lower-ROI channels should be optimized.

### Conclusion
The analysis provides data-driven insights into marketing channel performance and supports better budget allocation using ROI, conversion rate, acquisition cost, and engagement metrics.
